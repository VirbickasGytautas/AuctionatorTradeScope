# TradeScope 5.0.0-beta5 — Workspace Optimization

- Activity and data quality are now **one** tab under Market: one item selector, one refresh action, and two columns, both derived from the same local Auctionator data. The two previous analysis functions remain unchanged. `/ats quality` is an alias of `/ats activity`; existing saved options and old shortcuts are retained.
- The separate Quality sidebar entry is removed. Analytics now contains Indicators and Heatmap. Sidebar groups are re-spaced; 13 destinations total.
- The combined pane has contextual hover help for each metric and the same top-right `?` help (not a permanent sidebar).
- Terminal watchlist paging and pinning use the common bottom action row; Strategies show 7 candidates rather than 5. Portfolio, Journal and Craft Catalog rows use the canvas height more evenly.
- All money, scan, strategy, craft and journal calculations and SavedVariables remain unmodified. Combat close/lockdown is unchanged.
- Beta build only: WoW Forever in-game verification required. No GitHub tag / CurseForge publication.
